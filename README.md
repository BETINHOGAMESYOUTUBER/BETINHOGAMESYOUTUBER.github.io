# Betinho Games — Plataforma Curso FaceMaker PES 2021

Aplicação web completa de alta performance desenvolvida para o especialista em FaceMaker **Betinho Games** (José Silva).

## 🚀 Tecnologias Utilizadas
- **Next.js 16+** (App Router, React 19)
- **TypeScript**
- **Tailwind CSS v4** + Variáveis de Design Customizadas (Paleta Gamer Dark)
- **Lucide React** (Ícones acessíveis)
- **SEO Avançado** (OpenGraph, Twitter Cards, Sitemap.xml, Robots.txt, JSON-LD Schemas)
- **Camada de Analytics** (GA4, GTM, Meta Pixel, Google Ads)

## 📁 Rotas Disponíveis
- `/curso-facemaker`: Landing page profissional de vendas com 16 seções completas, CTA para checkout seguro e galeria de portfólio acessível.
- `/links`: Página leve e responsiva de links para a bio do Instagram com parâmetros UTM.
- `/politica-de-privacidade`: Documento legal sobre privacidade e LGPD.
- `/termos-de-uso`: Documento legal sobre termos e condições.
- `/politica-de-cookies`: Documento legal sobre uso de cookies.
- `/`: Redirecionamento automático para a página do curso.

## 🛠️ Como Executar Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Checagem de Linter
npm run lint

# Compilação de Produção
npm run build
```
